# S4 — Đề kiểm tra, kiểm tra đầu giờ, học sinh tham gia, realtime: Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> Cùng agent thực thi ngay sau khi viết. Chia: **S4a** quiz builder; **S4b** học sinh tham gia (mã lớp/QR → chọn tên → token thiết bị); **S4c** engine lượt kiểm tra + chấm + Socket.IO; **S4d** giao diện giáo viên điều khiển và học sinh làm bài.

**Goal:** Giáo viên ghép đề từ ngân hàng (chọn tay hoặc random theo thẻ, thời gian/điểm từng câu), phát đề vào buổi học đang mở theo chế độ Paced (giáo viên chuyển câu) hoặc Self-paced (mở hết, hạn chung); học sinh quét QR/nhập mã, chọn tên (nhớ thiết bị), làm bài trên điện thoại, xem điểm của mình khi kết thúc; chấm tự động (trả lời ngắn không phân biệt dấu/hoa thường), giáo viên sửa điểm; kết quả lưu theo học sinh theo buổi.

**Architecture:** "REST cho lệnh, Socket.IO cho trạng thái": mọi hành động (bắt đầu, chuyển câu, nộp bài) đi qua HTTP (idempotent, dễ retry); server phát `run:state` (trạng thái công khai đầy đủ) tới phòng `session:{id}` sau mỗi thay đổi (gom 250 ms). Khi (re)connect, client nhận ngay `run:state` → refresh/mất mạng đều khôi phục. PostgreSQL là nguồn sự thật; Redis làm adapter Socket.IO (tắt được bằng env khi test). Câu hỏi được **chụp snapshot** vào `QuizRunQuestion` lúc phát đề; xáo phương án theo lượt.

**Tech Stack:** `@nestjs/websockets`, `@nestjs/platform-socket.io`, `socket.io`, `@socket.io/redis-adapter` (ioredis), web `socket.io-client`.

## Quyết định trong slice

| #   | Quyết định                                                                                                                                                                                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Định danh học sinh: token ký HMAC (JwtService, payload `{ kind:'student', sub: deviceId, sid, cid }`, 180 ngày) đặt cookie `lh_st` (httpOnly, path `/`) **và** trả về cho client lưu localStorage, gửi lại qua `Authorization: Bearer` khi cookie bị chặn. Bảng `StudentDevice` lưu hash; giáo viên "gỡ thiết bị" = `revokedAt`. |
| 2   | Khóa roster (`rosterLocked`): tên đã có thiết bị đang hoạt động không thể được chọn từ thiết bị khác (409 `STUDENT_BOUND`). Không khóa: chọn lại tên từ máy khác tạo thiết bị mới, thiết bị cũ vẫn hợp lệ.                                                                                                                       |
| 3   | Mỗi buổi tại một thời điểm chỉ có một lượt chưa kết thúc (409 `RUN_ACTIVE`). Trạng thái: `lobby → in_progress → finished`. Paced: `currentIndex`, `questionOpenedAt`, `questionClosedAt`; Self-paced: `deadlineAt`, mọi câu mở tới hạn.                                                                                          |
| 4   | Nộp bài: một lần cho mỗi câu (unique `runQuestionId + studentId`); nộp lại trả lại bản đã có (`accepted:false`, idempotent). Paced chỉ nhận khi câu đang mở (kể cả trong `timeLimitSec` + 3 giây trễ mạng); Self-paced nhận tới `deadlineAt` + 3 giây.                                                                           |
| 5   | Chấm: một lựa chọn/đúng-sai = chọn đúng phương án; nhiều lựa chọn = đúng hết (all-or-nothing); trả lời ngắn = `normalizeText` khớp một trong `acceptedAnswers`. Điểm = `points` khi đúng, 0 khi sai. Không thưởng tốc độ; xếp hạng theo điểm rồi tổng `responseMs` tăng dần.                                                     |
| 6   | Học sinh chỉ thấy đúng/sai của mình sau khi câu đóng (paced) hoặc lượt kết thúc (self-paced); cuối lượt thấy điểm của mình + hạng. Bảng xếp hạng đầy đủ dành cho máy chiếu/giáo viên.                                                                                                                                            |
| 7   | Socket.IO một namespace `/rt`; xác thực trong `handshake.auth.token` (giáo viên: access JWT, học sinh: token thiết bị) hoặc cookie; máy chiếu: `role:'present'` không cần token (chỉ nhận dữ liệu công khai). Client `transports:['websocket']`. Phòng `session:{sessionId}`.                                                    |
| 8   | Sự kiện: `quiz_launched {sessionId, quizId, mode}`, `students_joined {sessionId, count}` (khi bắt đầu lượt), `quiz_completed {runId, participants, answered}`.                                                                                                                                                                   |

## Hợp đồng API (dưới `/api`)

**Quiz builder (JWT giáo viên)**

| Method & path                       | Body / trả về                                                         |
| ----------------------------------- | --------------------------------------------------------------------- |
| GET `/quizzes`                      | `QuizSummaryDto[]`                                                    |
| POST `/quizzes`                     | `CreateQuizInput` → 201 `QuizDetailDto`                               |
| GET/PATCH/DELETE `/quizzes/:id`     | `QuizDetailDto` / `UpdateQuizInput` / 204 (xóa mềm)                   |
| POST `/quizzes/:id/items`           | `{ questionIds }` → `QuizDetailDto` (bỏ trùng)                        |
| POST `/quizzes/:id/items/random`    | `{ count, filter }` → `QuizDetailDto` (random N câu chưa có trong đề) |
| PATCH `/quizzes/:id/items/:itemId`  | `{ timeLimitSec?, points? }` → `QuizDetailDto`                        |
| DELETE `/quizzes/:id/items/:itemId` | 204                                                                   |
| POST `/quizzes/:id/items/reorder`   | `{ itemIds }` → `QuizDetailDto`                                       |

**Học sinh tham gia (public / token học sinh)**

| Method & path                            | Body / trả về                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------- |
| GET `/join/:code`                        | `JoinInfoDto { class:{id,name,rosterLocked}, students:[{id,name,bound}] }`; mã sai → 404          |
| POST `/join/:code/pick`                  | `{ studentId }` → `{ token, student, class }` + cookie `lh_st`; 409 `STUDENT_BOUND` khi khóa      |
| GET `/student/me`                        | (token) `StudentMeDto { student, class, session: {id,status} \| null, run: {id,status} \| null }` |
| GET `/student/runs/:id`                  | (token) `StudentRunViewDto`                                                                       |
| POST `/student/runs/:id/answers`         | (token) `SubmitAnswerInput` → `{ accepted, answerId }`                                            |
| POST `/classes/:id/students/:sid/unbind` | (giáo viên) 204, thu hồi mọi thiết bị của học sinh                                                |

**Lượt kiểm tra (JWT giáo viên)**

| Method & path                                     | Body / trả về                                                                            |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| POST `/sessions/:id/runs`                         | `LaunchRunInput` → 201 `RunDetailDto`; 409 `RUN_ACTIVE`                                  |
| GET `/sessions/:id/runs`                          | `RunListItemDto[]`                                                                       |
| GET `/runs/:id`                                   | `RunDetailDto` (snapshot có đáp án, participants, answers, kết quả)                      |
| POST `/runs/:id/start` `/next` `/close` `/finish` | `RunDetailDto`                                                                           |
| PATCH `/runs/:id/answers/:answerId`               | `{ isCorrect }` → `RunDetailDto` (sửa điểm, tính lại kết quả)                            |
| GET `/runs/:id/public`                            | `RunPublicStateDto` (không auth; dùng cho máy chiếu khởi tạo và fallback khi socket lỗi) |

**Socket.IO** (`/rt`): client → `session:join {sessionId}`; server → `run:state RunPublicStateDto` (và `session:state {activeRunId}` khi lượt mới được tạo).

## Task

1. **Shared**: `quizzes/{schemas,types}.ts`, `runs/{schemas,types,grading}.ts` (+ spec chấm điểm 8 trường hợp), `students/{schemas,types}.ts`, `socket-events.ts`, ErrorCodes `RUN_ACTIVE`, `STUDENT_BOUND`, `RUN_NOT_OPEN`.
2. **API S4a**: module `quizzes` (service/controller) + e2e (CRUD, thêm/bỏ trùng, random theo filter không trùng, sửa thời gian/điểm, reorder, xóa mềm, của người khác 404).
3. **API S4b**: `student-auth` (token thiết bị, guard mở rộng `@StudentRoute()`), module `join` (`/join/:code`, pick, `/student/me`), unbind; e2e (mã sai 404, chọn tên → cookie + token, khóa roster 409, gỡ thiết bị → token cũ 401, me trả session/run đang mở).
4. **API S4c**: module `runs` (launch với snapshot + xáo, start/next/close/finish, submit + chấm, override, kết quả + xếp hạng, public state), `realtime` (gateway `/rt`, RedisIoAdapter khi `REALTIME_ADAPTER=redis`, `RunBroadcaster` gom 250 ms), analytics events; e2e (paced đầy đủ: launch → start → HS nộp đúng/sai → close → next → finish → kết quả/hạng; self-paced: hạn; nộp khi chưa mở → 409; nộp trùng → accepted:false; override; socket nhận `run:state` khi start).
5. **Web S4d**: `/app/quizzes` (danh sách, tạo), `/app/quizzes/[id]` (thêm từ ngân hàng với bộ lọc + random, sửa thời gian/điểm, sắp xếp); trong trang buổi học: dialog phát đề; `/app/runs/[id]` điều khiển (lobby/câu hỏi/đếm/kết quả/xếp hạng, link máy chiếu); học sinh: `/join`, `/join/[code]`, `/s/[sessionId]` (chờ → làm bài → điểm), hàng đợi retry nộp bài; `lib/socket.ts`.
6. Kiểm thử trình duyệt hai vai (giáo viên + học sinh ở context riêng), pipeline + e2e xanh, commit.
